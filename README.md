# Broome Dispatch: Gang Wars

A lightweight emergency dispatch simulator inspired by dispatch-management games.

## Features

- Police, Fire and Ambulance resources
- Gang-related incidents
- Vehicle crashes
- Fires
- Public safety rating
- Gang threat system
- Win/Lose conditions

## Play

Open:

index.html

or deploy to:

- GitHub Pages
- Netlify
- Vercel
